## 1. DBスキーマ (Database Schema)

### 1-1. USERSテーブル (USERS Table)

```sql
CREATE TABLE USERS (
  ID       INT          PRIMARY KEY AUTO_INCREMENT,  -- ユーザーID (User ID)
  NAME     VARCHAR(100) NOT NULL UNIQUE,             -- ユーザー名 (Username)
  PASS     VARCHAR(255) NOT NULL                     -- パスワード (Password)
);
```

| カラム (Column) | 型 (Type) | 制約 (Constraint) | 説明 (Description) |
|-----------------|-----------|-------------------|-------------------|
| ID | INT | PK / AUTO_INCREMENT | ユーザーID |
| NAME | VARCHAR(100) | NOT NULL / UNIQUE | ユーザー名 |
| PASS | VARCHAR(255) | NOT NULL | パスワード（平文） |

> ⚠️ 将来対応予定: E_MAIL / CREATED_AT / DELETED_FLAG 等の追加カラムあり（Memo.java参照）

---

### 1-2. MUTTERSテーブル (MUTTERS Table)

```sql
CREATE TABLE MUTTERS (
  ID      INT          PRIMARY KEY AUTO_INCREMENT,  -- つぶやきID (Mutter ID)
  USER_ID INT          NOT NULL,                    -- ユーザーID (User ID / FK)
  TEXT    VARCHAR(140) NOT NULL,                    -- つぶやき内容 (Content)
  FOREIGN KEY (USER_ID) REFERENCES USERS(ID)
);
```

| カラム (Column) | 型 (Type) | 制約 (Constraint) | 説明 (Description) |
|-----------------|-----------|-------------------|-------------------|
| ID | INT | PK / AUTO_INCREMENT | つぶやきID |
| USER_ID | INT | NOT NULL / FK | 投稿者のユーザーID |
| TEXT | VARCHAR(140) | NOT NULL | つぶやき内容 |

> ⚠️ 将来対応予定: CREATED_AT（投稿日時）カラムの追加

## 2. パッケージ構成 (Package Structure)

```
src/main/java/
├── dao/
│   ├── MuttersDAO.java       # MUTTERS テーブル操作 (CRUD)
│   └── UserDAO.java          # USERS テーブル操作
├── model/
│   ├── Mutter.java           # つぶやきエンティティ (Mutter Entity)
│   ├── User.java             # ユーザーエンティティ (User Entity)
│   ├── LoginLogic.java       # ログイン処理ロジック
│   ├── RegisterUserLogic.java# ユーザー登録ロジック
│   ├── PostMutterLogic.java  # つぶやき投稿ロジック
│   ├── GetMutterListLogic.java # つぶやき一覧取得ロジック
│   ├── SearchMutterLogic.java  # つぶやき検索ロジック
│   ├── UpdateMutterLogic.java  # つぶやき編集ロジック
│   └── DeleteMutterLogic.java  # つぶやき削除ロジック
├── servlet/
│   ├── Login.java            # POST /Login
│   ├── Logout.java           # GET  /Logout
│   ├── Main.java             # GET/POST /Main
│   ├── Register.java         # GET/POST /Register
│   ├── SearchMutter.java     # GET  /SearchMutter
│   ├── UpdateMutter.java     # GET/POST /UpdateMutter
│   └── DeleteMutter.java     # GET  /DeleteMutter
└── Memo.java                 # 開発メモ（非実行）

src/main/webapp/
├── index.jsp                 # TOP画面 / ログインフォーム
└── WEB-INF/
    ├── jsp/
    │   ├── main.jsp          # メイン画面
    │   ├── loginResult.jsp   # ログイン結果画面
    │   ├── logout.jsp        # ログアウト画面
    │   ├── registerView.jsp  # ユーザー登録フォーム
    │   ├── registerResult.jsp# ユーザー登録完了画面
    │   └── updateMutter.jsp  # つぶやき編集フォーム
    └── lib/
        └── mysql-connector-j-9.5.0.jar
```
